Apache Tomcat 是开源的 Java Servlet 容器，用于部署和运行 Java Web 应用。

部署流程：
1. 安装 JDK：Tomcat 9 需要 JDK 8+，Tomcat 10 需要 JDK 11+
2. 下载解压：tar -zxvf apache-tomcat-9.x.tar.gz
3. 配置环境变量：CATALINA_HOME 指向 Tomcat 安装目录
4. 启动：bin/startup.sh（Linux）或 bin/startup.bat（Windows）
5. 部署应用：将 war 包放入 webapps/ 目录，启动时自动解压部署

目录结构：
- bin/：启动停止脚本
- conf/：配置文件，核心是 server.xml
- lib/：Tomcat 自身依赖 jar
- webapps/：应用部署目录
- logs/：日志输出
- temp/：临时文件
- work/：JSP 编译后的 class

核心配置 server.xml：
- Connector：配置端口、协议、线程池
- Engine：Servlet 引擎
- Host：虚拟主机
- Context：应用上下文

性能调优要点：
1. JVM 参数：-Xms 初始堆、-Xmx 最大堆，生产环境建议二者相等避免动态扩容
2. 线程池：maxThreads 最大并发线程数（默认200），minSpareThreads 最小空闲线程
3. 连接器：maxConnections 最大连接数，acceptCount 排队队列长度
4. IO 模型：NIO（默认）、APR（性能最佳，需 native 库）
5. 压缩：compression="on" 开启 GZIP 压缩

常见问题：
- 端口冲突：netstat -ano | findstr 8080 查看占用
- 内存溢出：调整 -Xmx，检查是否存在内存泄漏
- 启动慢：检查 SecureRandom 熵源，可用 -Djava.security.egd=file:/dev/./urandom

国产化适配：宝兰德、中创等国产中间件兼容 Tomcat 标准，可在麒麟OS上稳定运行。
