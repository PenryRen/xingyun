## 概述

### 项目背景

本项目是一个基于 **LangChain** 和 **LangGraph** 框架的多智能体教育平台，旨在为学习麒麟系统操作与应用的学生提供智能化的学习辅助。系统采用**主管架构（Supervisor Architecture）**，通过一个主管 Agent 协调多个专业子 Agent，实现对学生学习过程的全面支持。

### 核心目标

- **智能化**：利用大语言模型的理解和生成能力，提供个性化的学习指导
- **模块化**：将复杂的教育功能拆分为独立的智能体，便于维护和扩展
- **数据驱动**：基于真实的学生数据进行分析和决策，提供针对性建议
- **可扩展**：采用松耦合设计，支持新增功能和智能体

### 主要功能

1. **考试分析**：分析试卷，识别薄弱知识点
2. **学情管理**：维护学生学情档案，跟踪学习进度
3. **智能组卷**：根据学生情况生成个性化测试卷
4. **学习答疑**：解答学习问题，提供概念解释

## 设计思路

### 1. 主管架构（Supervisor Architecture）

系统采用**中心化的主管架构**，由一个主管 Agent 负责：
- **意图识别**：分析用户输入，理解需求
- **任务路由**：将任务分配给最合适的子 Agent
- **结果整合**：汇总子 Agent 的输出，返回给用户

**优势**：
- 统一的入口点，简化用户交互
- 智能路由，提高任务处理效率
- 易于扩展新的子 Agent

### 2. 模块化设计

将教育功能拆分为四个独立的子 Agent 模块：

```
┌─────────────────────────────────────────┐
│           主管 Agent                      │
│  (Supervisor)                           │
│  - 意图识别                              │
│  - 任务路由                              │
└──────────────┬──────────────────────────┘
               │
       ┌───────┼───────┬──────────┐
       │       │       │          │
       ▼       ▼       ▼          ▼
   ┌───────┐ ┌───────┐ ┌───────┐ ┌───────┐
   │考试   │ │学情   │ │学情   │ │办学   │
   │分析   │ │分析   │ │检测   │ │助手   │
   │Agent  │ │Agent  │ │Agent  │ │Agent  │
   └───────┘ └───────┘ └───────┘ └───────┘
```

每个子 Agent 专注于特定领域，具有：
- 独立的系统提示词（System Prompt）
- 专用的工具集（Tools）
- 专属的状态管理（State Management）

### 3. 工具增强（Tool-Augmented）

每个 Agent 通过**工具调用**来扩展能力：
- **考试分析 Agent**：试卷分析工具、薄弱点识别工具
- **学情分析 Agent**：档案管理工具、进度跟踪工具
- **学情检测 Agent**：智能组卷工具、题库管理工具
- **办学助手 Agent**：知识库查询工具

### 4. 记忆管理（Memory Management）

系统实现了**会话记忆**功能：
- 使用 LangGraph 的 Checkpoint 机制
- 支持多线程会话（Thread-based）
- 滑动窗口管理消息历史（默认保留最近 40 条消息）

### 5. 知识库集成（Knowledge Base）

集成**向量数据库**和**RAG（检索增强生成）**技术：
- 使用 FAISS 作为向量存储
- 支持文档的向量化和相似度搜索
- 为办学助手提供准确的知识支持

### 1. 主管工作流（LearningSupervisorWorkflow）

**位置**：`src/graphs/learning_workflow.py`

**职责**：
- 实现主管架构的核心逻辑
- 管理子 Agent 的生命周期
- 处理用户请求的路由和调度

**关键方法**：

```python
class LearningSupervisorWorkflow:
    def __init__(self, use_local: bool = False):
        # 初始化主管 LLM
        self.llm = ModelManager.get_llm(use_local=use_local, temperature=0.3)
        
        # 初始化四个子 Agent
        self.exam_analysis_agent = build_exam_analysis_agent(use_local=use_local)
        self.learning_profile_agent = build_learning_profile_agent(use_local=use_local)
        self.learning_assessment_agent = build_learning_assessment_agent(use_local=use_local)
        self.teaching_assistant_agent = build_teaching_assistant_agent(use_local=use_local)
        
        # 构建工作流图
        self.workflow = self._build_workflow()
        self.app = self.workflow.compile(checkpointer=MemorySaver())
    
    def _supervisor_node(self, state: LearningWorkflowState) -> LearningWorkflowState:
        """
        主管节点：分析用户意图，决定调用哪个子 Agent
        """
        # 构建主管提示词
        supervisor_prompt = """你是麒麟系统教育平台的主管 Agent..."""
        
        # 调用 LLM 进行决策
        response = self.llm.invoke([
            SystemMessage(content=supervisor_prompt),
            *messages
        ])
        
        # 解析决策结果
        decision = response.content.strip().lower()
        next_agent = decision if decision in valid_agents else "teaching_assistant"
        
        return {"next_agent": next_agent}
    
    def _route_to_agent(self, state: LearningWorkflowState) -> str:
        """路由函数：根据主管决策路由到对应子 Agent"""
        return state.get("next_agent", "teaching_assistant")
```

**工作流程**：

1. 用户输入 → 主管节点
2. 主管分析意图 → 决策调用哪个子 Agent
3. 路由到子 Agent → 子 Agent 处理请求
4. 子 Agent 返回结果 → 添加到消息历史
5. 返回主管节点 → 再次决策或结束

### 4. 知识库（Knowledge Base）

- `vector_store.py`：向量存储（FAISS）

```python
class KnowledgeBase:
    def __init__(self, word_dir: str, index_path: str, use_local: bool = True):
        # 初始化向量存储
        self.vector_store = VectorStore(index_path=index_path, use_local=use_local)
        
        # 初始化文档处理器
        self.document_processor = DocumentProcessor(word_dir=word_dir)
    
    def build_knowledge_base(self) -> int:
        """构建知识库"""
        # 处理文档
        documents = self.document_processor.process_documents()
        
        # 添加到向量存储
        self.vector_store.add_documents(documents)
        
        return len(documents)
    
    def get_relevant_context(self, query: str, k: int = 3) -> str:
        """获取相关上下文"""
        docs = self.vector_store.search(query, k=k)
        
        if not docs:
            return ""
        
        # 合并文档内容
        context = "\n---\n".join([doc.page_content for doc in docs])
        return context
```

**文档处理**：
```python
class DocumentProcessor:
    def process_documents(self) -> List[Document]:
        """处理 word 目录下的所有文档"""
        documents = []
        
        # 遍历 word 目录
        for file_path in os.listdir(self.word_dir):
            if file_path.endswith('.docx'):
                # 处理 Word 文档
                doc = self._process_docx(file_path)
                documents.append(doc)
            elif file_path.endswith('.pdf'):
                # 处理 PDF 文档
                doc = self._process_pdf(file_path)
                documents.append(doc)
            elif file_path.endswith('.txt'):
                # 处理文本文件
                doc = self._process_txt(file_path)
                documents.append(doc)
        
        return documents
```

### 5. 模型管理（Model Manager）

**位置**：`src/models/model_manager.py`

**功能**：
- 统一管理大语言模型和 Embedding 模型
- 支持远程模型和本地模型的降级策略
- 提供配置管理

**核心方法**：
```python
class ModelManager:
    @staticmethod
    def get_llm(
        use_local: bool = False,
        model_name: Optional[str] = None,
        temperature: float = 0.7,
        streaming: bool = True
    ):
        """
        获取大语言模型实例
        
        策略：优先使用远程模型，失败时回退到本地模型
        """
        # 优先使用远程模型（OpenAI 兼容接口）
        try:
            api_key = os.getenv("OPENAI_API_KEY")
            base_url = os.getenv("OPENAI_BASE_URL")
            
            if not api_key:
                raise Exception("远程模型 API 密钥未配置")
            
            remote_model_name = model_name or "gpt-4o-mini"
            
            llm = ChatOpenAI(
                model=remote_model_name,
                api_key=api_key,
                base_url=base_url,
                temperature=temperature,
                streaming=streaming
            )
            
            # 测试连接
            llm.invoke("test")
            return llm
        except Exception as e:
            print(f"远程模型初始化失败，回退到本地模型：{e}")
        
        # 回退到本地模型
        try:
            local_model_name = model_name or "mistralai/Mistral-7B-v0.1"
            llm = HuggingFaceHub(repo_id=local_model_name)
            chat_model = ChatHuggingFace(llm=llm)
            return chat_model
        except Exception as e:
            raise Exception("所有模型初始化失败")
    
    @staticmethod
    def get_embedding(use_local: bool = True, model_name: Optional[str] = None):
        """
        获取 Embedding 模型实例
        
        策略：默认使用本地模型（性能更好）
        """
        if use_local:
            try:
                local_model_name = model_name or "sentence-transformers/all-MiniLM-L6-v2"
```

## 实现算法

### 1. 意图识别算法（Intent Recognition）

**位置**：`src/graphs/learning_workflow.py::_supervisor_node`

**算法描述**：
使用 LLM 进行零样本分类（Zero-shot Classification），将用户意图分类到预定义的 Agent 类别。

**实现**：
```python
def _supervisor_node(self, state: LearningWorkflowState) -> LearningWorkflowState:
    # 构建分类提示词
    supervisor_prompt = """你是麒麟系统教育平台的主管 Agent...
    
    可用子 Agent:
    1. exam_analysis - 考试分析 Agent
       触发关键词：分析、试卷、薄弱点、错题
    2. learning_profile - 学情分析 Agent
       触发关键词：档案、学情、记录、进度
    3. learning_assessment - 学情检测 Agent
       触发关键词：试卷、测试、组卷、强化
    4. teaching_assistant - 办学助手 Agent
       触发关键词：什么是、为什么、怎么、如何
    
    决策规则:
    1. 分析用户最新的消息
    2. 选择最合适的子 Agent
    3. 如果意图不明确，选择 teaching_assistant
    4. 如果用户表示结束，选择 end
    
    输出格式：只输出 Agent 名称
    """
    
    # 调用 LLM
    response = self.llm.invoke([
        SystemMessage(content=supervisor_prompt),
        *messages  # 用户消息历史
    ])
    
    # 解析结果
    decision = response.content.strip().lower()
    valid_agents = ["exam_analysis", "learning_profile", "learning_assessment", "teaching_assistant", "end"]
    next_agent = decision if decision in valid_agents else "teaching_assistant"
    
    return {"next_agent": next_agent}
```

**优势**：
- 无需训练数据
- 灵活适应新的意图类别
- 利用 LLM 的语义理解能力

**位置**：`src/tools/paper_generator_tool.py::generate_intelligent_paper`

**算法描述**：
基于规则和启发式的题目筛选和组合算法。

**实现**：
```python
def generate_intelligent_paper(
    student_name: str,
    student_id: str,
    paper_type: str,  # "normal" | "enhanced"
    topic: str,
    difficulty: str,  # "easy" | "medium" | "hard"
    question_count: int
) -> str:
    # 1. 查询题库
    questions = get_questions(topic=topic, limit=100)
    
    # 2. 难度筛选
    difficulty_map = {
        "easy": (0.0, 0.4),
        "medium": (0.4, 0.7),
        "hard": (0.7, 1.0)
    }
    min_diff, max_diff = difficulty_map[difficulty]
    filtered_questions = [
        q for q in questions 
        if min_diff <= q['difficulty'] < max_diff
    ]
    
    # 3. 强化测试：优先选择薄弱知识点相关题目
    if paper_type == "enhanced":
        student = get_student_by_student_id(student_id)
        profile = get_learning_profile(student.id)
        weak_points = json.loads(profile.weak_points)
        
        # 分离薄弱知识点题目和其他题目
        weak_questions = []
        other_questions = []
        for q in filtered_questions:
            if is_weak_related(q, weak_points):
                weak_questions.append(q)
            else:
                other_questions.append(q)
        
        # 70% 薄弱知识点题目，30% 其他题目
        weak_count = int(question_count * 0.7)
        selected = random.sample(weak_questions, min(weak_count, len(weak_questions)))
        remaining = question_count - len(selected)
        selected.extend(random.sample(other_questions, min(remaining, len(other_questions))))
        filtered_questions = selected
    
    # 4. 随机选择题目
    if len(filtered_questions) > question_count:
        selected_questions = random.sample(filtered_questions, question_count)
    else:
        selected_questions = filtered_questions
    
    # 5. 构建试卷
    paper = {
        "paper_name": f"{topic} 测试",
        "questions": selected_questions
    }
    
    return json.dumps(paper, ensure_ascii=False, indent=2)
```

**算法特点**：
- 难度分层：确保试卷难度符合要求
- 针对性强：强化测试优先覆盖薄弱知识点
- 随机性：避免题目重复

### 3. 知识点掌握度计算算法

**位置**：`src/tools/learning_profile_tool.py::update_knowledge_progress`

**算法描述**：
基于加权平均的知识点掌握度更新算法。

**实现**：
```python
def update_knowledge_progress(
    student_id: str,
    knowledge_point: str,
    mastery_level: float  # 本次练习的掌握度 (0.0-1.0)
):
    # 查询学生
    student = get_student_by_student_id(student_id)
    
    # 查询现有进度记录
    progress = get_knowledge_progress_record(student.id, knowledge_point)
    
    if progress:
        # 更新现有记录（加权平均）
        current_mastery = progress.mastery_level
        practice_count = progress.practice_count
        
        # 新的掌握度 = (当前掌握度 * 练习次数 + 本次掌握度) / (练习次数 + 1)
        new_mastery = (current_mastery * practice_count + mastery_level) / (practice_count + 1)
        
        update_progress(
            student.id,
            knowledge_point,
            mastery_level=round(new_mastery, 3),
            practice_count=practice_count + 1,
            correct_count=progress.correct_count + (1 if mastery_level >= 0.6 else 0)
        )
    else:
        # 创建新记录
        create_progress_record(
            student.id,
            knowledge_point,
            mastery_level=mastery_level,
            practice_count=1,
            correct_count=1 if mastery_level >= 0.6 else 0
        )
```

**公式**：
```
新掌握度 = (当前掌握度 × 练习次数 + 本次掌握度) / (练习次数 + 1)
```

**特点**：
- 考虑历史表现
- 近期表现权重更高
- 平滑更新，避免大幅波动

### 4. 向量相似度搜索算法（Vector Similarity Search）

**位置**：`src/knowledge/vector_store.py::search`

**算法描述**：
使用 FAISS 进行向量相似度搜索，基于余弦相似度。

**实现**：
```python
class VectorStore:
    def __init__(self, index_path: str, use_local: bool = True):
        # 初始化 Embedding 模型
        self.embedding = ModelManager.get_embedding(use_local=use_local)
        
        # 初始化或加载 FAISS 索引
        if os.path.exists(index_path):
            self.index = faiss.read_index(index_path)
        else:
            self.index = faiss.IndexFlatL2(embedding_dimension)
        
        self.documents = []
        self.index_path = index_path
    
    def add_documents(self, documents: List[Document]):
        """添加文档到向量存储"""
        # 提取文本
        texts = [doc.page_content for doc in documents]
        
        # 生成向量
        embeddings = self.embedding.embed_documents(texts)
        
        # 添加到 FAISS 索引
        self.index.add(np.array(embeddings).astype('float32'))
        
        # 保存文档元数据
        self.documents.extend(documents)
        
        # 保存索引
        faiss.write_index(self.index, self.index_path)
    
    def search(self, query: str, k: int = 3) -> List[Document]:
        """搜索相关文档"""
        # 生成查询向量
        query_embedding = self.embedding.embed_query(query)
        
        # FAISS 搜索（返回最近的 k 个向量）
        distances, indices = self.index.search(
            np.array([query_embedding]).astype('float32'),
            k
        )
        
        # 返回对应的文档
        results = []
        for idx in indices[0]:
            if idx < len(self.documents):
                results.append(self.documents[idx])
        
        return results
    
    def search_with_score(self, query: str, k: int = 3) -> List[tuple[Document, float]]:
        """搜索相关文档并返回相似度分数"""
        query_embedding = self.embedding.embed_query(query)
        distances, indices = self.index.search(
            np.array([query_embedding]).astype('float32'),
            k
        )
        
        results = []
        for i, idx in enumerate(indices[0]):
            if idx < len(self.documents):
                # 将 L2 距离转换为相似度分数
                similarity_score = 1 / (1 + distances[0][i])
                results.append((self.documents[idx], similarity_score))
        
        return results
```

**相似度计算**：
- 使用 L2 距离（欧几里得距离）
- 转换为相似度分数：`similarity = 1 / (1 + distance)`

### 5. 消息滑动窗口算法（Message Windowing）

**位置**：`src/agents/agent.py::_windowed_messages`

**算法描述**：
保留最近 N 条消息，避免上下文过长导致 token 超限。

**实现**：
```python
MAX_MESSAGES = 40  # 默认保留最近 40 条消息（20 轮对话）

def _windowed_messages(old, new):
    """
    滑动窗口：只保留最近 MAX_MESSAGES 条消息
    
    Args:
        old: 旧的消息列表
        new: 新的消息
    
    Returns:
        更新后的消息列表
    """
    from langgraph.graph.message import add_messages
    
    # 合并新旧消息
    all_messages = add_messages(old, new)
    
    # 只保留最近 MAX_MESSAGES 条
    return all_messages[-MAX_MESSAGES:]
```

**优势**：
- 控制 token 使用量
- 保留最近的上下文
- 避免信息过载

- **LangChain** (1.0.3)：大语言应用开发框架
- **LangGraph** (1.0.2)：基于图的工作流引擎
- **FastAPI** (0.121.2)：高性能 API 框架

### 大模型

- **远程模型**：OpenAI 兼容接口（gpt-4o-mini）
- **本地模型**：HuggingFace Hub（Mistral-7B）
- **Embedding**：
  - 本地：sentence-transformers/all-MiniLM-L6-v2
  - 远程：text-embedding-3-small

### 向量数据库

- **FAISS**：Facebook AI Similarity Search
- 支持向量相似度搜索
- 本地文件存储

### 数据库

- **达梦数据库**（DM Database）
- **SQLAlchemy** (2.0.44)：ORM 框架
- 替代原有的 Supabase

### 文档处理

- **docx2python**：Word 文档处理
- **pypdf**：PDF 文档处理
- **openpyxl**：Excel 文档处理

### 存储

- **MemorySaver**：LangGraph 内存存储
- **S3**：对象存储（可选）

### 依赖管理

- **requirements.txt**：Python 依赖包管理

## 扩展指南

### 1. 添加新的子 Agent

**步骤**：

1. 创建 Agent 文件：`src/agents/new_agent.py`

```python
from langchain.agents import create_agent
from langgraph.graph import MessagesState
from typing import Annotated
from storage.memory.memory_saver import get_memory_saver
from models.model_manager import ModelManager

# 导入工具
from tools.new_tool import new_tool_function

class NewAgentState(MessagesState):
    messages: Annotated[list, add_messages]

def build_new_agent(use_local: bool = False):
    llm = ModelManager.get_llm(use_local=use_local, temperature=0.5)
    
    tools = [new_tool_function]
    
    system_prompt = """你是新领域的专家..."""
    
    return create_agent(
        model=llm,
        system_prompt=system_prompt,
        tools=tools,
        checkpointer=get_memory_saver(),
        state_schema=NewAgentState,
    )
```

2. 更新主管工作流：`src/graphs/learning_workflow.py`

```python
from agents.new_agent import build_new_agent

class LearningWorkflowState(TypedDict):
    next_agent: Optional[Literal[
        "exam_analysis", 
        "learning_profile", 
        "learning_assessment", 
        "teaching_assistant",
        "new_agent",  # 新增
        "end"
    ]]

class LearningSupervisorWorkflow:
    def __init__(self, use_local: bool = False):
        # 初始化新 Agent
        self.new_agent = build_new_agent(use_local=use_local)
        
        # 添加节点
        workflow.add_node("new_agent", self._new_agent_node)
        
        # 更新路由
        workflow.add_conditional_edges(
            "supervisor",
            self._route_to_agent,
            {
                "exam_analysis": "exam_analysis",
                "learning_profile": "learning_profile",
                "learning_assessment": "learning_assessment",
                "teaching_assistant": "teaching_assistant",
                "new_agent": "new_agent",  # 新增
                "end": END
            }
        )
        
        # 添加边
        workflow.add_edge("new_agent", "supervisor")
```

### 3. 添加新的数据库表

**步骤**：

1. 定义模型：`src/storage/database/shared/model.py`

```python
class NewModel(Base):
    """新表"""
    __tablename__ = 'new_table'
    
    id: Mapped[int] = mapped_column(Integer, primary_key=True)
    name: Mapped[str] = mapped_column(String(128), nullable=False)
    created_at: Mapped[datetime.datetime] = mapped_column(DateTime(timezone=True), server_default=func.now())
```

2. 创建数据库操作函数：`src/tools/data_base_tools.py`

```python
def get_new_model_by_id(model_id: int):
    session = get_session()
    try:
        model = session.query(NewModel).filter(NewModel.id == model_id).first()
        return model
    finally:
        session.close()

def create_new_model(name: str):
    session = get_session()
    try:
        model = NewModel(name=name)
        session.add(model)
        session.commit()
        session.refresh(model)
        return model
    except Exception as e:
        session.rollback()
        return None
    finally:
        session.close()
```

1. **主管架构**：统一的意图识别和任务路由

6. **灵活降级**：支持远程和本地模型切换
